What a report establishes

The read-only generator checks selected finalized accounts through Mesh: expected addresses, owners, account shapes, code pins, liabilities and close receipts. An amount appears only when at least two configured sources agree. A changed code pin remains visible. No market quote is inferred from custody.

Different RPC origins do not establish independent operators. Public release pins, a reviewed source policy and a complete weekly index are still prerequisites. The first four actual weekly burns must be executed and published before the token phase is complete. Local fixture executions do not satisfy that exit.
